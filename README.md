# 岐黄脉镜 — AI 中医脉诊

> 取名自《黄帝内经》岐伯与黄帝论医之典，"脉镜"寓意以现代传感器为镜、映射古法脉象。

基于 Apple Watch 生理数据的中医脉诊分析系统，纯前端实现。

## 功能特点

- 📱 支持 Apple Health 导出 ZIP 文件解析
- 💓 自动提取心率、HRV、ECG 数据
- 🏥 基于中医 28 脉理论进行智能分析
- 📊 可视化显示脉象特征和诊断结果
- 🎨 中式传统界面设计
- 🔒 所有数据本地处理，保护隐私

## 可识别脉象

### 高置信度脉象（传感器直接判定）

- **迟脉**（HR < 60）- 寒证、阳虚
- **数脉**（HR > 90）- 热证、阴虚
- **疾脉**（HR > 120）- 阳极阴竭
- **促脉**（快心率 + 不规则早搏）- 阳盛实热
- **结脉**（慢心率 + 不规则停搏）- 阴盛气结
- **代脉**（规律性漏拍）- 脏气衰微
- **弦脉**（RMSSD<20ms + LF/HF>2.0）- 肝胆病、痛证
- **缓脉**（RMSSD>50ms + HR 60-75）- 平脉或脾虚
- **洪脉**（R波振幅 > 1.5mV）- 气分热盛
- **细脉**（R波振幅 < 0.5mV）- 气血两虚
- **滑脉**（RR变异系数 < 0.03）- 痰湿、妊娠

## 使用方法

1. 访问 **[在线演示](https://spa3k.github.io/tcm-pulse-web/)**
2. 从 Apple Watch 导出健康数据
3. 上传 ZIP 文件到系统
4. 查看脉象分析和诊断建议

## 数据来源

- 心率（BPM）：Apple Watch 全天后台采集
- 心率变异性（HRV）：睡眠和静息时自动测量
- 心电图（ECG）：需手动打开 ECG App 录制 30 秒

## 技术栈

- 纯 HTML/CSS/JavaScript
- Tailwind CSS - 样式框架
- Chart.js - 数据可视化
- fflate - ZIP 文件解析

## 隐私说明
